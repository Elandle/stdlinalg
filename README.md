# stdlinalg

My personal Fortran "standard library" for linear algebra. Just a bunch of code in one big module so I can drag it around easily when working on different things.

Depends on my stduse.

Note that this is very much under development (just take what you might need or be risky and take everything).
As of now I have just ran through a bunch of my code, found what pieces might fit, and pasted them here.
I am in the process of cleaning it up and adding to it.
